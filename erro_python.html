Ops! O Python não está instalado

Para rodar o servidor local você precisa do Python 3. É rápido:

  1. Baixe em python.org/downloads.
  2. Abra o instalador e marque a opção "Add python.exe to PATH" (ou "Use admin privileges / py launcher").
  3. Clique em Install Now.
  4. Feche tudo e execute o servidor.bat novamente.
